# 📊 Sistema de Projeção de Frequência

Sistema desenvolvido em **Python** como exercício de lógica de programação.

O programa analisa a frequência do aluno em uma determinada matéria e calcula quanto tempo será necessário para atingir **75% de frequência**, caso o aluno esteja abaixo do mínimo.

## 🎯 Funcionalidades

* Cadastro do nome da matéria;
* Registro de aulas dadas;
* Registro de faltas;
* Cálculo automático das presenças;
* Cálculo da frequência atual;
* Verificação da frequência mínima de **75%**;
* Cálculo das aulas necessárias para recuperação;
* Estimativa de semanas necessárias;
* Estimativa de meses necessários;
* Relatório da situação da matéria.

## 🧠 Conceitos praticados

## ▶️ Como executar

Tenha o **Python 3** instalado.

Execute o arquivo pelo terminal:

```bash
python nome_do_arquivo.py
```

Depois, informe os dados solicitados pelo sistema.

## 📌 Regra

O sistema considera **75% como frequência mínima**.

Caso o aluno esteja abaixo desse valor, o programa calcula uma projeção considerando que ele **não terá novas faltas** durante o período de recuperação.
